LUME HOTEL · PRIVACIDADE

Privacidade e proteção de dados

1. Quais dados coletamos?

Nome, e-mail, telefone opcional, quantidade de hóspedes, quarto escolhido e datas da estadia.

2. Para que utilizamos os dados?

Os dados são utilizados exclusivamente para demonstrar o funcionamento do sistema de reservas.

3. Onde os dados ficam armazenados?

As reservas ficam armazenadas no armazenamento local do navegador (localStorage), neste dispositivo.

4. Compartilhamento de dados

Esta demonstração não possui integração com servidores de reservas ou sistemas de pagamento.

5. Exclusão dos dados

Você pode excluir as reservas pelo botão Limpar na área de reservas salvas.

6. Seus direitos

A LGPD (Lei nº 13.709/2018) estabelece direitos relacionados ao tratamento de dados pessoais, incluindo acesso, correção e eliminação, conforme as hipóteses legais.
